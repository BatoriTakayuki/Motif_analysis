# Motif Analysis

ブラウザでDNA配列のモチーフ密度、gRNAの位置、bigWigのスコアを調べるローカル解析ツールです。CpGの場合はモチーフに `CG` を指定します。

このリポジトリはアプリの実行に必要なファイルだけを含みます。選択式の参照ゲノムは初回利用時にUCSCから取得し、サーバーの `genome_cache/` に保存します。入力配列、bigWig、解析結果は同梱していません。

## 起動方法

### Windows・Docker Desktop

1. Docker Desktopを起動します。
2. このリポジトリをクローン、またはZIPでダウンロードして展開します。
3. `start.cmd` をダブルクリックします。
4. ブラウザで <http://localhost:8765> を開きます。

使用中は起動したウィンドウを開いておき、終了時は `Ctrl+C` を押してください。初回はDockerイメージと依存パッケージのダウンロードにネット接続が必要です。

### ターミナルからDockerで起動（Windows・macOS・Linux）

リポジトリのフォルダで実行します。

```sh
docker build -t motif-analysis .
docker run --rm -p 127.0.0.1:8765:8765 motif-analysis
```

<http://localhost:8765> を開きます。8765番ポートを別のアプリが使用中なら、`-p 127.0.0.1:8766:8765` に変更して <http://localhost:8766> を開いてください。

### Pythonで直接起動

Python 3.12と、依存パッケージを導入できる環境で実行してください。Windowsでは `pyBigWig` の導入が難しい場合があるため、Dockerを推奨します。

```sh
python -m pip install -r requirements.txt
python server.py
```

`index.html` を直接開く場合、貼り付けた配列の解析を利用できます。FASTAのアップロード・配列の位置検索・bigWig解析にはサーバーの起動が必要です。

### 同じWi-Fi・LANで複数人が利用する

サーバーPCのIPアドレスを指定して起動します。この環境では、アプリのフォルダ内で次を実行します。

```sh
python3 server.py --host 10.40.3.211 --port 8765
```

利用者は同じWi-Fi・LANから <http://10.40.3.211:8765> を開きます。サーバーPCのファイアウォールでTCP 8765への接続を許可し、Wi-Fiの端末間通信が有効であることを確認してください。IPアドレスが変わった場合は起動コマンドとアクセスURLを変更します。

- ログインはありません。ネットワークからこのサーバーへ接続できる人が利用できます。
- アップロードしたFASTA・bigWigはCookieで識別するブラウザごとのセッションに保存します。別セッションのファイルIDを指定しても読み取り・集計はできません。
- 同じブラウザプロファイルのタブはセッションを共有します。共用PCで利用者を分ける場合は、別のブラウザプロファイルを使用してください。解析条件と結果は各タブ内に保持します。
- 最後のリクエスト完了から24時間経過したセッションは、その後のサーバーへのアクセス時に削除します。処理中のセッションは削除しません。サーバー終了時には全セッションの一時ファイルを削除します。Cookieが失われた場合や期限切れ・再起動後はファイルを再アップロードしてください。
- サーバー側の同時処理は既定で4リクエストまでです。上限を超えた場合はメッセージを表示するので、少し待って再実行してください。`--max-jobs 2` などで1〜32に変更できます。ブラウザ側のモチーフ計算は各端末で行います。
- 起動オプションの `--search-genome`・`--bigwig`・`--query` で管理者が指定した入力は、全利用者への共通の初期データです。アップロードしたデータがほかの利用者の初期データになることはありません。

Dockerで共有する場合は、既存の `start.cmd` の代わりにアプリのフォルダで次のコマンドを使用します。Python・bigWig用依存関係はイメージ内に含まれるため、ホストPCへのpipインストールは不要です。8765番ポートを使う別のサーバーが動いている場合は先に終了してください。

```sh
docker compose up -d --build
```

バックグラウンドで動作し、Dockerの再起動後にも自動起動します。停止は `docker compose stop`、再開は `docker compose start`、ログの確認は `docker compose logs --tail 50` です。参照ゲノムのキャッシュはホスト側の `genome_cache/` に残り、コンテナを作り直しても再利用できます。別のIPで使う場合は `MOTIF_HOST_IP` を設定してください。サーバーの継続稼働には、そのPCとDockerを起動したままにしてください。

### 参照ゲノムを選択する

「参照ゲノムの版」で次の選択肢を指定します。

- **マウス GRCm38（mm10）**：既定値。GRCm38のUCSC名はmm10です。
- **マウス GRCm39（mm39）**：別のマウスゲノム版。mm10との座標の互換性はありません。
- **自分のFASTAを使用**：従来どおり検索用・領域解析用のFASTAを指定します。

選択したゲノムで「配列を自動検索 → 解析」または「ゲノム領域を指定」からの領域解析ができます。既定のmm10は最初の実行時、別の版は選択時に準備します。未取得の場合、サーバーがUCSC公式のFASTAを取得し、MD5チェックサムと染色体長を確認して検索用データを作ります。初回は数分以上かかることがあります。進捗は画面に表示され、2回目以降はキャッシュを使用します。共通参照は読み取り専用で共有し、利用者のアップロードデータは引き続きセッションごとに分離します。CSVとSVGにも選択したゲノム版を記録します。

事前にmm10を準備する場合は、サーバーを起動する前に次を実行できます。

```sh
python3 server.py --prepare-genome mm10
```

参照の保存先は `--genome-cache` で変更できます。mm10は圧縮FASTAと検索用データで合計約4 GBの空き容量が必要です。FASTAは [UCSC mm10](https://hgdownload.soe.ucsc.edu/goldenPath/mm10/bigZips/)・[UCSC mm39](https://hgdownload.soe.ucsc.edu/goldenPath/mm39/bigZips/) の配布データを使用します。染色体名は `chr1` 形式です。bigWigは選択したゲノムと同じ版・染色体名のものを使ってください。ゲノム版を選択してもbigWigの座標変換は行いません。

## 使い方

1. 参照ゲノムの版を選び、DNA配列を貼り付けるか検索配列FASTAから入力します。「ゲノム領域を指定」で選択ゲノムの一部を取得できます。独自の参照FASTA（gzip対応）も指定できます。
2. モチーフ配列を入力します。`CG`、`CCWGG`、`NGG` など、IUPAC塩基記号を使えます。
3. 「Sliding window」または「Bin（固定幅）」を選び、幅を指定して「解析する」を押します。
4. gRNA配列を入力して「決定・マーク」を押すと、完全一致する位置を色分けした縦の点線で表示します。名前付き配列やFASTA形式にも対応します。
5. bigWigと同時に表示する場合は「重ねて表示」を選び、手持ちの `.bw` を読み込みます。緑はモチーフ密度（左軸）、紫はbigWigスコア（右軸）です。左右の軸は別スケールです。
6. 「bigWigを別の設定にする」で、モチーフとbigWigの集計方式・幅を個別指定できます。bigWigは元の値（追加平滑化なし）も選択できます。図中の表示名も変更できます。
7. 結果をCSV、BED、bedGraph、図をSVGまたは高解像度PNGとして保存できます。図の右上で形式を選びます。方式が異なる場合、表はトラックを切り替えて表示し、CSVではトラックを区別します。

「サンプルを試す」はアプリ内で生成するデモ配列です。研究用の入力データや解析結果を読み込む機能ではありません。BEDファイルで指定領域を集計する機能は「その他」の詳細設定にあります。

### ChIP-AtlasからSRXのbigWigを取得する

1. 「参照ゲノムの版」で、ChIP-Atlasのデータと同じ版を選びます。マウスGRCm38なら `mm10` です。
2. 「重ねて表示」または「bigWigのみ」を選びます。
3. 「ChIP-Atlasから取得」に `SRX`、`ERX`、または `DRX` で始まる実験IDを入力し、「取得」を押します。
4. ChIP-Atlasのメタデータ、選択したゲノム版、bigWigの染色体長が一致した場合だけ解析用データとして読み込みます。

ChIP-seq、ATAC-seq、DNase-seqの通常のcoverage bigWigに対応します。Bisulfite-seqはmethylation値とcoverage値が別ファイルのため、SRXからの自動取得対象には含めていません。入力したIDに選択中のゲノム版がない場合、ChIP-Atlasに存在する版をエラー表示します。取得したbigWigはアップロードファイルと同様にブラウザセッションへ紐づき、24時間使わない場合またはサーバー終了時に削除されます。

データはChIP-Atlas公式のメタデータAPIと公開bigWigを使用します。配布規則は [ChIP-Atlas公式リポジトリ](https://github.com/inutano/chip-atlas) と [ChIP-Atlas Agent Guide](https://chip-atlas.org/agents) を参照してください。ChIP-Atlas側の更新・停止時には取得できない場合があります。

### 配列のゲノム座標を自動検索する

参照ゲノムの版を選び、「配列を自動検索」を押します。bigWig自体にはDNA配列がないため、位置検索には選択ゲノムのFASTAを使用します。「自分のFASTAを使用」では検索用FASTAをアップロードします。

完全一致を両鎖で検索し、見つからない場合は1塩基の置換・挿入・欠失を許す候補を探します。複数候補または1塩基差がある場合は、利用者が候補を選択します。1塩基差の候補を選んだ場合、モチーフ密度・gRNA検索にはその領域の**参照ゲノム配列**を使用します。この状態は画面・SVG・PNG・CSVに記録されます。入力配列の変異を維持した座標投影は行いません。

検索する配列はACGTのみ、20 bp〜2 Mbです。全ゲノムでの検索には時間がかかる場合があります。

## 集計方法・座標

- **Sliding window**：片側幅を `w` として `2w+1` bpの窓を、指定ステップで移動します。窓全体が表示領域に収まる位置だけを集計します。
- **Bin**：入力配列・選択領域の先頭から、指定幅の重ならない区間に分割します。染色体全体の0位置を基準にはしません。末尾の短いbinも含めます。
- **モチーフ密度**：一致の開始位置が区間内にある件数を、実際の区間長で割ります。境界をまたぐ一致は開始位置側に数えます。表示領域の右端より先に続き、一致を確認できないモチーフは数えません。逆相補検索では同じ開始位置を二重計数しません。
- **bigWig**：データがある塩基を対象に平均・最小・最大・coverageを集計します。coverageは区間内で値が存在する割合です。欠測を0に置き換えず、保存された0は平均に含めます。配列からbigWigスコアを生成するものではありません。
- **gRNA**：表示領域内の完全一致を検索します。PAM・切断位置の推定、ミスマッチ許容、全ゲノムのオフターゲット検索は行いません。点線は一致範囲の中央です。
- **座標**：画面は1-based・両端を含む形式です。BED・bedGraph・CSVは0-based・終了位置を含まない形式です。画面の `chr1:101–200` はBEDの `chr1 100 200` に対応します。

FASTAとbigWigは同じゲノムアセンブリ・染色体名のものを使ってください。`chr1` と `1` の自動変換は行いません。曖昧塩基を含む区間や参照範囲外の区間は欠測として扱います。

CSVは欠測行を含み、BED・bedGraphは有効行だけを保存します。BinのCSVには設定幅 `bin_bp` と実際の区間長 `interval_bp` を記録します。Sliding windowのbedGraphは重複を避けるため窓の中心1 bpに出力します。Binは区間全体に出力します。BED領域が重複している場合はbedGraph出力を止めます。

## データの保存と制限

解析はブラウザとサーバーで行います。参照ゲノムの初回取得時はUCSCへ、SRX取得時は実験IDの照会と公開bigWigの取得のためChIP-Atlasへサーバーから接続します。利用者が貼り付けた配列や手元のbigWigをこれらのサービスへ送ることはありません。LAN利用時、FASTA・bigWigのアップロードやサーバー側の解析に必要な配列はサーバーPCへ送信します。アップロードまたはChIP-Atlasから取得したbigWigはセッションごとの一時領域に保存され、期限切れ時または通常終了時に削除されます。共通参照の `genome_cache/` はセッション期限や再起動では削除しません。再起動後、個人の入力ファイルと取得済みSRXは再読み込みしてください。解析結果は必要に応じてダウンロードして保存します。

表示配列は最大2 Mb、1回の集計は最大100,000行、アップロードは1ファイル20 GiBまでです。FASTAの各行は1,048,576文字以下に改行してください。gzip FASTAは展開して処理するため、十分なディスク空き容量が必要です。配列のBED集計は合計50 Mbまでです。

## ファイル構成

| ファイル | 用途 |
| --- | --- |
| `index.html` / `style.css` | 画面とデザイン |
| `app.js` / `core.js` | 画面操作・配列解析・描画・出力 |
| `server.py` | FASTA・bigWigの読み込みと集計API |
| `requirements.txt` | Python依存パッケージ |
| `Dockerfile` / `.dockerignore` | Docker実行環境 |
| `compose.yaml` | LAN共有・参照ゲノムの永続保存を含む起動設定 |
| `test_sessions.py` | セッション分離・ゲノムキャッシュ・bigWig集計のテスト |
| `start.cmd` | Windows用の起動ファイル |
| `.gitignore` | 入力データや解析結果の誤登録を防ぐ除外設定 |

GitHubへ共有する際は、このフォルダだけをリポジトリにしてください。FASTA・bigWig・CSVなどのデータ拡張子と `data/`・`results/` 等のフォルダは `.gitignore` で除外しています。Dockerのビルド対象もアプリ本体に限定しています。
